# Bakery_Electron_Game_Prototype

A game where you choose your bakery items and it generates the final dish.

Built with HTML, CSS, JavaScript, and Electron for desktop packaging.

## Status
Work in progress. The game logic works in the browser. Electron packaging is still being fixed.

## Run it
Open `index.html` in your browser.
